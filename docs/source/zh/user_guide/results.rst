读取预测与解释输出
============================================================

主要输出
------------------------------------------------------------

- ``Training_Set_Detailed_*.csv``：建模池特征与 SHAP。
- ``Feature_<name>``：描述符值。
- ``SHAP_<name>`` / ``SHAP_Std_<name>``：有效验证出现中的归因均值/离散程度。
- ``Test_Set_Detailed_*.csv``：显式指定的留出样本。
- ``Realtest_Pred`` / ``Realtest_Pred_Std``：原始集成预测与模型间离散程度。
- ``Target``：输入目标，不是新测量。

引擎使用重复随机划分。重复过少时某些样本可能从未进入验证集，旧聚合实现可能
含零填充值；报告指标前要检查验证覆盖。模型间离散程度不是校准置信区间。

自动特征筛选属于探索，不是论文另行冻结 benchmark 的嵌套交叉验证实现。
科学比较应预先固定特征，或把完整筛选过程放入训练折。永久测试集不能参与筛选、
解释排名与调参。

SHAP 是模型归因，不是测量效应或候选分数。实际查看见 :doc:`../examples/interpretation`。
