Scope and core concepts
============================================================

Whole-molecule descriptors summarize composition, shape and electronic structure.
Surface descriptors summarize ESP, ALIE and LEAE on a specified molecular surface.
Local descriptors select an element, aligned fragment or automated region.
SHAP attributes model predictions to features; it does not prove causality.

Select a region before inspecting test outcomes: :doc:`../descriptors/index`.
An isolated-molecule descriptor does not simulate an electrode, solvent interface
or adsorbed state. Record charge, protonation, conformer, solvent and surface settings.
Ordinary SHAP remains; the previous ranking extension is removed: :doc:`../migration`.
