Citation and contact
============================================================

Cite the research preprint for the method and the actual software version/commit
for the implementation you used.

Research preprint
------------------

Yuming Su, Yangtao Chen, Yiheng Dai and Cheng Wang.
*Explain and Go Beyond with Surfacia: A Surface-Descriptor based Workflow for Interpretable Molecular Machine Learning*.
ChemRxiv, version 1, posted **27 August 2026**.
`DOI: 10.26434/chemrxiv.15007949/v1 <https://doi.org/10.26434/chemrxiv.15007949/v1>`_.

This is a public preprint, not a journal acceptance. Its original title is kept
verbatim. The archived v1 predates the 4.0.0 scope revision and the latest
interpretability-focused manuscript; it should not be read as a description of
every feature in the current package. A newer public preprint version was not
confirmed in the Crossref title search on 19 October 2026.
